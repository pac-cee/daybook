# Kigali Weather

Weather app and shared feature library for Daybook. See the [workspace README](../README.md), [architecture](../docs/ARCHITECTURE.md) and [verification](../docs/VERIFICATION.md).

Run `flutter pub get`, then `flutter run`. Entry point: `lib/main.dart`. The live API needs no key for noncommercial use. All four city coordinates come from the lesson guide. The sibling Daybook project imports this package to reuse the weather, storage and UI modules.
